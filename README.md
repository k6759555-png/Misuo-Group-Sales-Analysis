# Sales Analysis – Misuo Group Company (2024)

Tools: Excel, Power Query, Pivot Tables

# Project Overview:
This project analyzes Misuo Group Company’s 2024 sales data to evaluate overall performance, product trends, and delivery efficiency. The dataset required extensive cleaning due to inconsistencies and shuffled records, which was handled using Power Query and Excel techniques.

# Key Objectives:

Assess total sales and order trends

Track cancelled orders and on-time delivery rates

Identify top-performing products and platforms

Highlight monthly performance trends for strategic insights

# Key Insights:

Total sales: $1.28M

Cancelled orders: 18% of total

On-time delivery: 48% of orders

Top-selling product: Beds, via Homzmart platform, accounting for $869K (over half of total sales)

Best month: September showed peak sales; start and end of the year had lower performance

Skills & Techniques:

Advanced data cleaning and data preparation

Pivot Tables and charts for analysis and visualization

Power Query for combining, transforming, and standardizing messy datasets

KPI calculation and business insights extraction

Repository Contents:

Excel workbook with dashboard and analysis sheets

Documentation of KPIs and metrics analyzed

Instructions for exploring and interacting with the dashboard

Report with Results, Insights, and Recommendations 

# Impact:
Provides actionable insights for inventory planning, platform optimization, and improving on-time delivery, supporting data-driven decision-making for the company.
